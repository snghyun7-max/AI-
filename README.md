# 📋 교실 출석체크 시스템

강의실 자리 배치 기반의 웹 출석체크 프로그램입니다.  
GitHub Pages로 배포하여 학생들이 URL 하나로 바로 접속할 수 있습니다.

---

## 🔗 바로가기

👉 **[출석체크 열기](https://[GitHub아이디].github.io/[저장소이름]/)**

> 위 링크를 본인의 GitHub Pages URL로 교체하세요.

---

## ✨ 주요 기능

- **자리 배치 시각화** — 10줄 × 5책상 × 3자리 (최대 150석)
- **관리자 모드** — 출석/결석 직접 처리, 명렬표 확인, 결과 CSV 내보내기
- **학생 모드** — 내 자리 클릭 한 번으로 출석 체크
- **엑셀/CSV 업로드** — 출석부 파일 업로드로 학생 이름 일괄 등록
- **양식 다운로드** — 출석부 작성용 CSV 양식 제공

---

## 🚀 사용 방법

### 교수 / 조교 (관리자)

1. URL 접속 → 기본값이 **관리자 모드**
2. `엑셀 업로드` 탭에서 출석부 CSV/xlsx 업로드
3. 자리 배치에서 학생 자리 클릭 → 출석/결석 처리
4. 수업 종료 후 `CSV 내보내기`로 결과 저장

### 학생

1. 교수가 공유한 URL 접속
2. 우측 상단 **학생 모드로** 버튼 클릭
3. 교실 배치도에서 내 자리 클릭 → 출석 버튼 누르기

## 📁 엑셀 업로드 양식

| 번호 | 이름 |
|------|------|
| 1    | 홍길동 |
| 2    | 김철수 |
| ...  | ...  |

- 첫 행은 헤더 (자동 인식)
- `.csv` 또는 `.xlsx` 형식 모두 지원
- 이름 순서대로 1줄 1번 자리부터 자동 배치

## ⚠️ 주의사항

- 학생이 체크한 내용은 **해당 브라우저에서만** 유지됩니다 (서버 저장 없음)
- 매 수업마다 출석 결과는 `CSV 내보내기`로 저장해 두세요
- 학생 출력 결과를 실시간으로 공유하려면 별도 DB 연동이 필요합니다
